# Difference Generator (gendiff)

Una herramienta de línea de comandos (CLI) desarrollada en Python que compara dos archivos de configuración (en formato JSON) y muestra las diferencias organizadas alfabéticamente.

## Requisitos
- Python 3.10+
- Poetry

## Instalación

Clona el repositorio e instala las dependencias:

```bash
git clone https://github.com/Chalo-nov/python-project-174.git
cd python-project-174
poetry install
